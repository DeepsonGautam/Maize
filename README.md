# Maze

Sleepy Maze is a maze adventure game where you play as a sleepy character and travel through 8 difficult levels. The game features smooth animations, a slight horror theme, responsive controls, and a clean UI.

## Features

* 8 challenging levels
* Smooth animations
* Horror-themed atmosphere
* Interactive home screen
* Level selection menu

## Controls

* Arrow Keys -- Move

## Goal

Complete all 8 mazes and reach the end.
